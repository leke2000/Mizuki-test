我是一名开发工程师，日常主要负责**数据可视化大屏（Dashboard）**的前端开发，同时也使用 Java 编写后端接口服务。工作里和图表、数据、接口打交道最多；屏幕之外，也想在这里认真记录生活。

## 我在做什么

- **大屏前端开发**：基于 Vue 3 + TypeScript + Vite 构建数据可视化大屏，使用 ECharts、DataV 等图表库呈现业务数据
- **后端接口服务**：基于 Java 17 + Spring Boot 开发并维护 `ejet-screen-management` 接口服务，为大屏提供数据支撑
- **状态管理与工程化**：Pinia、Vue Router、Axios 封装、Element Plus 组件开发，关注性能与可维护性
- **这个博客本身**：基于 Astro 搭建、部署在 Vercel 上的个人站点，源码开放在 [GitHub](https://github.com/leke2000/Mizuki-test)

## 技术栈

**前端**：Vue 3 · TypeScript · Vite · Pinia · Vue Router · Element Plus · ECharts · DataV · Axios

**后端**：Java 17 · Spring Boot

**其他**：Git · Astro · Tailwind CSS · Linux 基础运维
